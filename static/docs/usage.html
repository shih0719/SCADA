Part 2 · Configuration & Use

配置使用

給負責設定系統的人和每天操作的人：怎麼建立空間、設備和迴路，怎麼在平面圖上開關燈，以及怎麼用場景和排程自動化。 系統還沒架好的話，請先看安裝架設。

每個畫面的頁首都有同一組導覽按鈕，目前所在的畫面會亮起來。

每天使用的畫面：看平面圖上的燈號、點一下開關燈、整區全開全關、套用場景。

02基本概念

開始設定前，先認識系統裡的三種資料：

名稱代表什麼例子
空間（Space）一張平面圖，通常是一個樓層或一個區域。3F 辦公室、2F 倉庫
設備（Device）一台 Modbus TCP Gateway / 控制器，用 IP、Port、Slave ID 來辨識。1F 配電箱 Gateway（192.168.1.50:502）
迴路（Circuit）設備上的一個線圈（Coil），對應一組燈。每個迴路屬於一個空間、接在一台設備上，並且有一個平面圖上的位置。窗邊燈＝1F 配電箱的線圈 1

一台設備可以控制好幾個空間的迴路；一個空間裡的迴路也可以來自不同設備。

03第一次配置

以下流程全部在編輯模式（/edit）完成。

  1. 建立空間

    在左側「Spaces」輸入名稱（例如「3F 辦公室」），按 Add Space。新空間會自動被選取。

  2. 上傳平面圖

    在 Spaces 卡片下方按「選擇檔案」，選一張 PNG 或 JPG（最大 10MB），再按 Upload Floorplan。右側就會顯示這張平面圖。

  3. 新增設備

    展開「Devices」，填寫 Gateway 的資料（各欄位說明見設備欄位），按 Add Device。系統會馬上開始輪詢這台設備。

  4. 新增迴路

    在「Circuits」輸入迴路名稱、選擇設備、填線圈位址，按 Add Circuit。新的迴路會先出現在黃色的「Not yet placed on the floorplan」清單裡。

  5. 把迴路放到平面圖上

    在黃色清單裡按該迴路的 Place on map（按鈕會變成「Click map…」），再到平面圖上點燈具的位置，燈號就放好了。

  6. 測試

    點一下燈號，確認現場的燈有跟著開關；拖曳燈號可以微調位置，放開滑鼠時會自動儲存。

迴路很多？

可以用 CSV 批量匯入一次建立所有的空間、設備和迴路，之後只需要逐一放到平面圖上。

04編輯模式詳解

空間（Spaces）

  • 點空間名稱就能切換，右側會換成該空間的平面圖。
  • 重新上傳平面圖會換掉原本的圖片；迴路座標是以圖片的原始像素記錄的，換成尺寸不同的圖片時，請重新檢查燈號位置。
  • 按名稱右邊的 ✕ 刪除。如果空間裡還有迴路，會先跳出確認視窗；按「確定」會連同裡面所有迴路一起刪除，按「取消」則什麼都不會動。

設備（Devices）

點「▸ Devices」展開或收合這張卡片。

欄位說明表單預設值
Device name顯示用的名稱，例如「1F 配電箱 Gateway」。—
IP addressGateway 的 IPv4 位址或主機名稱。127.0.0.1
PortModbus TCP 的 port，實體設備通常是 502。15020（模擬器用）
Slave IDModbus 的 Unit / Slave ID。1
Poll ms每隔多少毫秒讀一次狀態。數字越小，畫面越即時，但對設備和網路的負擔也越大。1500
Timeout ms每次讀寫最多等多久，超過就判定這次失敗。1000
  • 清單左側的燈號：● 綠色代表已啟用，灰色代表停用（整列也會變淡）。
  • 取消勾選 enabled 會停止輪詢這台設備，它的迴路會顯示為離線；適合設備維修時使用。
  • 新增、修改、停用設備都會立即生效，不需要重啟伺服器。
  • 刪除的規則和空間相同：如果還有迴路接在這台設備上，會先詢問是否一起刪除。

迴路（Circuits）

這張卡片顯示的是目前選取的空間的迴路。

  • 線圈位址（Coil address）是從 0 開始算的 Modbus 線圈位址，請對照 Gateway 的點位表。同一台設備重複使用同一個位址不會被擋下，但請確認這是你要的設定。
  • 右上角的 ⇩ 匯出 CSV 會下載這個空間的所有迴路（格式見CSV）。
  • 在編輯模式的平面圖上：拖曳燈號可以移動位置，點一下則會開關燈（和操作頁面一樣）。

05CSV 批量匯入／匯出

適合一次建立大量迴路，或者先匯出、在 Excel 裡修改後再匯回去。

欄位

space_name,device_name,device_ip,device_port,device_slave_id,coil_address,name
欄位說明
space_name空間名稱。找不到同名的空間時會自動建立。
device_name設備名稱。找不到同名的設備時會自動建立，這時下面三欄必填。
device_ip / device_port / device_slave_id只在新建設備時使用；已經存在的設備會忽略這三欄，不會覆寫原本的設定。
coil_address線圈位址（0 以上的整數）。
name迴路名稱。
circuit_id（選填）填入既有迴路的編號時，這一行會變成更新該迴路（名稱、位址、空間、設備），並保留它在平面圖上的位置。匯出的 CSV 會自動帶這一欄。
 
space_name,device_name,device_ip,device_port,device_slave_id,coil_address,name
3F辦公室,1F配電箱Gateway,192.168.1.50,502,1,0,主燈
3F辦公室,1F配電箱Gateway,,,,1,窗邊燈
2F倉庫,2F配電箱Gateway,192.168.1.51,502,1,0,走道燈

匯入步驟

  1. 選擇檔案

    在「CSV 批量匯入 Circuit」卡片選擇 .csv 檔。系統會立刻做一次預覽，這時還不會寫入任何資料。

  2. 檢查預覽

    預覽會列出會新建哪些空間和設備，以及每一行的結果：新建、更新、警告或錯誤。有錯誤的行不會被匯入，其他行不受影響。

  3. 確認匯入

    按 確認匯入（N 筆） 才會真正寫入；按 取消 則放棄。匯入完成後，新的迴路會出現在「未放置」清單裡，等你放到平面圖上。

用 Excel 編輯時，請存成 CSV UTF-8 格式，中文名稱才不會變成亂碼。

06日常操作

操作頁面（/）是給值班人員用的，這裡不能修改設定，不用擔心誤刪資料。

  • 切換空間：點左側「Spaces」裡的名稱。
  • 開關單一迴路：點平面圖上的燈號，燈號會先立刻改變；如果寫入失敗，會恢復原狀、閃紅色，並在上方顯示錯誤訊息。狀態未知（離線）的迴路點了不會有反應。
  • 整區全開／全關：按右上角的 全部開 或 全部關，確認後會對目前空間的所有迴路下指令。完成後會顯示成功幾筆；有失敗時會列出失敗的迴路名稱。
  • 套用場景：按左側「場景」清單裡的 套用。
  • 上方的統計：迴路總數、亮燈數、熄燈數、離線數，以及即時更新的指示燈；資料讀取失敗時，指示燈會變成紅色的「輪詢失敗」。

剛開啟頁面時，如果看到「伺服器剛重啟，狀態同步中…」，請等幾秒，等燈號讀取完成再操作。

資料過舊有一段時間沒有讀到新資料

離線／未知連不到設備，狀態不可信
  • 資料過舊：超過「輪詢間隔 × 3」或 5 秒（取較長者）沒有成功讀取。燈號顯示的是最後一次讀到的狀態，僅供參考。
  • 離線／未知：系統不會沿用最後的狀態冒充現況，所以這時無法判斷燈是開還是關，也無法點擊切換。設備恢復連線後，一個輪詢週期內會自動恢復正常。
  • 把滑鼠移到燈號上，可以看到迴路名稱、線圈位址和目前狀態。

08場景

場景是一組「哪些迴路要開、哪些要關」的組合，例如「上班模式」或「下班關燈」。一個場景可以同時包含不同空間的迴路。場景在場景與排程頁面（/automation）建立，在操作頁面套用。

建立場景

  1. 輸入場景名稱
  2. 逐一設定迴路

    清單會列出所有空間的所有迴路，每一列都有三個選項：不設定（套用時不碰這個迴路）、開、關。

  3. 按「建立場景」
  • 按場景旁的 編輯，會把內容載入下方表單，改完按 儲存變更；按 取消編輯 則放棄修改。
  • 套用場景時，就算其中幾個迴路失敗（例如某台設備離線），其他迴路仍然會照常執行，結果訊息會列出失敗的迴路。
  • 刪除場景時，使用這個場景的排程也會一起被刪除。

09定時排程

排程會在指定的時間、指定的星期幾，自動套用一個場景。排程只能套用場景；如果想要「每天 18:30 把 3F 全部關掉」，請先建立一個把 3F 所有迴路設成「關」的場景。

建立排程

  1. 填寫名稱

    例如「平日下班關燈」。

  2. 選擇要套用的場景
  3. 設定時間

    24 小時制，以伺服器主機的時間為準，不是你這台電腦的時間。

  4. 點選星期幾

    點一下選取（變成藍色），再點一下取消。至少要選一天。

  5. 確認「啟用」有勾選，按「建立排程」

排程清單怎麼看

  • 左邊的大字是觸發時間，下方的燈號是綠色代表啟用中，灰色代表停用（整張卡片也會變淡）。
  • 七個小圓圈代表日～六，亮藍色的是有排程的日子。
  • 「最後觸發」顯示上一次自動執行的時間。
  • 想暫停排程但不刪除，取消勾選 啟用 即可。
要知道的限制
  • 系統每 30 秒檢查一次排程，實際觸發的時間可能比設定的晚幾十秒。
  • 如果在預定時間伺服器剛好沒有在執行（例如正在重啟），這一次就會跳過，不會事後補做。

10系統狀態

「系統狀態」頁（/status）每 4 秒自動更新，用來檢查每台設備的通訊品質。

欄位說明
整體狀態ok 代表一切正常；只要有任一台啟用中的設備連續失敗 3 次以上，就會變成 degraded。
連線狀態這台設備目前是否連得上。
成功率／平均延遲以最近 20 次輪詢計算。成功率下降或延遲變高，通常代表網路不穩或設備負載過重。
連續失敗次數達到 3 次會以警示色顯示。
最後成功時間最後一次成功讀取的時間。

11備份與還原

在編輯模式最下方的「備份與還原」卡片操作。

備份

按 ⇩ 下載備份，會下載一個 scada-backup-<時間>.zip，裡面包含所有設定（空間、設備、迴路、座標、場景、排程）和所有平面圖。建議在大幅修改設定之前，以及定期都備份一次，並把檔案存到別台電腦。

還原

  1. 選擇備份檔

    在「還原備份（.zip）」選擇之前下載的 zip，確認視窗按「確定」。

  2. 看到「還原成功」

    這時平面圖已經換成備份裡的版本，但設定資料還沒有。

  3. 重新啟動伺服器

    重啟後，資料庫才會換成備份的內容（舊的資料庫會保留為 data/scada.db.bak）。重啟的方式見安裝架設：常駐服務。

還原會覆蓋目前的所有資料

包含所有設定和平面圖。如果不確定，請先下載一份目前的備份再還原。格式不正確的檔案會被拒絕，目前的資料不會受影響。

12常見問題

點燈號沒有反應？

如果燈號是紅色斜線加「?」，代表系統讀不到這個迴路的狀態，所以不能切換。請到「系統狀態」頁確認設備是否連線。

現場的燈已經切換了，畫面卻慢了一兩秒？

這是正常的。畫面每 1.5 秒更新一次，伺服器也是依設備的輪詢間隔去讀取，所以會有短暫延遲。

燈號位置跑掉了？

通常是換了一張尺寸不同的平面圖。到編輯模式把燈號拖回正確位置即可，放開滑鼠就會自動儲存。

上傳平面圖時出現 403？

這是部署設定的問題，請系統管理員參考安裝架設：疑難排解。

可以讓其他系統控制燈嗎？

可以。外部系統的串接方式寫在專案內的 EXTERNAL_API.md。
